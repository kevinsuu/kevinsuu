## Order Management System

### [kevinsuu/OrderManagerSystem](https://github.com/kevinsuu/OrderManagerSystem)

A production-oriented **microservice-based order management system** designed to demonstrate scalable backend architecture.

**Architecture**

```text
Client
  │
  ▼
API Gateway
  │
  ├── Auth Service
  ├── Product Service
  ├── Order Service
  ├── Payment Service
  └── Notification Service
         │
         ▼
 PostgreSQL / Redis
```

**Engineering stack**

`Go` · `Gin` · `gRPC` · `PostgreSQL` · `Redis` · `JWT` · `Docker` · `Kubernetes` · `Nginx`

Also includes:

* API Gateway architecture
* Authentication & authorization
* Service separation by domain
* Redis caching
* REST + gRPC communication
* Dockerized development environment
* Kubernetes deployment
* GitHub Actions CI/CD
* Prometheus / Grafana monitoring
* Centralized logging architecture

> This project represents how I approach backend system design rather than just CRUD API development.

## Universal Trading Remote

### [kevinsuu/Technical-Analysis-Google-Plugin](https://github.com/kevinsuu/Technical-Analysis-Google-Plugin)

A Chrome extension designed to provide a unified control layer across multiple securities trading websites.

Key engineering challenges solved:

* **Closed Shadow DOM** for UI isolation from third-party websites
* Service Worker execution for browser extension architecture
* Handling website **Content Security Policy (CSP)** restrictions
* Cross-platform configuration for multiple brokerage websites
* Persistent watchlists and user preferences
* Stock symbol autocomplete with debounced search
* Custom action recorder based on DOM selectors
* Automated extension versioning during builds

`JavaScript` · `Chrome Extension` · `Shadow DOM` · `Service Worker` · `Webpack`
